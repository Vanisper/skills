# Skills

A personal Codex skills collection.

个人 Codex skills 仓库。

## Available Skills

- `git-workflow`: Reusable Git workflow skill with bilingual Chinese/English references for commits, branch merges, rollback, remotes, and tags.

## Structure

- `<skill>/SKILL.md`: entry instructions and metadata
- `<skill>/agents/openai.yaml`: UI-facing metadata
- `<skill>/references/`: detailed topic references

## Notes

- Skill ids and directory names stay in English.
- Chinese and English references can coexist in the same skill.
- Add new skills as sibling directories under the repository root.
